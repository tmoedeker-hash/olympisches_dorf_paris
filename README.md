# Leporello — Das olympische Dorf von Paris

Ein digitales, mobil-optimiertes Leporello zu Architektur und Städtebau des olympischen Dorfs Paris 2024. Horizontales Scroll-Snap simuliert das Aufklappen einer echten Leporello-Faltbroschüre.

## Lokal ansehen
Einfach `index.html` im Browser öffnen — keine Build-Schritte, keine Abhängigkeiten außer Google Fonts (CDN).

## Auf GitHub Pages hosten
1. Neues Repository auf GitHub anlegen (z. B. `leporello-paris`).
2. `index.html` (und optional dieses `README.md`) in den Root des Repos hochladen.
3. Unter **Settings → Pages** als Quelle den `main`-Branch (Root) auswählen.
4. Nach kurzer Zeit ist die Seite unter `https://<dein-username>.github.io/<repo-name>/` erreichbar.

## Inhalt anpassen
Alle Texte, Statistiken und Panel-Anzahl liegen direkt in `index.html` als klar abgegrenzte `<section class="panel">`-Blöcke — neue Panels lassen sich einfach kopieren und anpassen.

## Bildmaterial
Die Seite verwendet bewusst gezeichnete Liniengrafiken statt Fotografien, um Lizenzfragen zu vermeiden. Für eine öffentliche Version empfiehlt es sich, eigenes oder lizenziertes Bildmaterial (z. B. offizielle Pressebilder von SOLIDEO/Paris 2024) zu ergänzen.
